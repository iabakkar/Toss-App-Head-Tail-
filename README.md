# Toss App (Head/Tail)

A fun coin toss simulation using JavaScript.

## 🚀 Features

* 🎲 Random Head or Tail
* 🖼️ Image changes dynamically
* ⚡ One-click interaction

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

## 📸 Preview

Click the button and see either **Head** or **Tail**.

## 💡 Learning

* Random number generation 🎯
* Conditional statements 🔀
* DOM updates 📺

## ▶️ How to Use

1. Click **Flip the coin!**
2. See the result instantly
